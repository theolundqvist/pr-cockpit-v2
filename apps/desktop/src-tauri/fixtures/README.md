# PR Cockpit fixture inventory

This directory contains deterministic M1 data-layer fixtures generated by:

```bash
cargo run -p desktop --bin fixture-build
```

## Files

- `seed.sql`: generated SQL seed script (accounts/repos/users/PRs/notifications + timeline metadata).
- `cockpit_fixture.db`: SQLite fixture database produced by running migrations then inserting deterministic data.
- `blobs/`: content-addressed blob payloads for fixture patch content.

## Inventory

- 1 account (`acct_demo`) with token metadata only (`token_kind`, `scopes`) and no token secret.
- 3 repositories and repo subscription rows.
- 40 users + 1 org.
- 200 open pull requests across 3 repos (for inbox fan-in).
- 200 notifications (`notif_1..notif_200`).
- Active PR `pr_1` contains:
  - 55 comments (issue/review/review_thread_reply mix),
  - 10 reviews,
  - 5 review threads,
  - 8 commits linked through `pr_commits`,
  - 2 check suites and 10 check runs (+ annotations),
  - 30 changed files,
  - one synthesized 5000-line unified diff stored as a zstd patch blob.
- Ancillary rows for milestone/project/labels/reviewers/assignees/worktree/pending mutation/id mapping/sync cursor/rate-limit bucket.

## Notes

- Fixture blobs are stored in the same `<app_data_dir>/blobs/<sha256-prefix>/<sha256>` layout used in production.
- `Db::open_fixture()` copies `cockpit_fixture.db` and `blobs/` into an ephemeral runtime directory, then opens that copy.
