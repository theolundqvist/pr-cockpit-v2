Token safety + renderer isolation tests pass.
- **One real M1 design call surfaced during finalize**: the perf-bench comparator now has two thresholds per metric — a PLAN §10 hard budget (immutable contract) and a runner-calibrated baseline (tunable noise floor). Documented in DECISIONS.md. M2 should preserve this split.
- **Verifier-failed → fix → reverify loop cost two extra cloud-agent runs** (m1-fix-gates, m1-reverify) plus one third for m1-bench-baselines. None of the failures were functional gaps; they were CI-runner-class hygiene problems (lint config, Linux deps in two CI jobs, perf jitter). Worth flagging because the loop nearly doubled wall-clock on the M1 tail; pre-baking the cloud image would absorb most of it.
- **Recurring environment friction**: every worker installed `libwebkit2gtk-4.1-dev libgtk-3-dev libsoup-3.0-dev libssl-dev pkg-config` (Tauri/git2 build deps), and the perf/smoke workers additionally bootstrapped `xvfb` + Playwright WebKit. This is recurring waste. Strong recommendation in the next section.
- **Two non-blocking caveats** captured in `artifacts/m1-smoke/notes.txt`: (1) the cloud-agent VM never boots a real Tauri window — the smoke runs are headless WebKit only; the markdown timeline + diff anchoring are verified end-to-end but a human-eye Tauri pass is still owed. (2) The fixture diff corpus has only `.rs` and `.ts` files, so the diff-viewer tree-sitter coverage on `.md` is exercised only via comrak/corpus and not via the in-diff highlighter.
- **Orchestrate-catalog drift**: the orchestrate model catalog's `gpt-5.5-high-fast` selection (`{id: gpt-5.5, params: [reasoning, fast]}`) is rejected by the cloud SDK because the SDK requires a `context` param too. I swapped every worker to `gpt-5.3-codex-high-fast` (works as-is) and left the verifier on `claude-opus-4-7`. Recorded in `attention.log`. The orchestrate skill author should bump the catalog.
- **Subtree decomposition retro**: a 9-worker serial chain (bootstrap → data → auth → api/sync → markdown → ipc → frontend → perf/corpus → finalize) + 1 verifier was the right shape for this M1 — each worker carried a meaty, low-coupling slice, and the dependsOn chain meant downstream workers inherited upstream code cleanly without merge tasks. The serial wall-clock cost about 7 hours total (8 worker runs of 15-90 min each, half of them on the long side); a parallel decomposition would have introduced O(n²) merge work across `src-tauri/Cargo.toml`, `src-tauri/src/lib.rs`, and the IPC bindings. The two follow-up workers (fix-gates, baselines) added ~30 min each and were strictly worth it.
